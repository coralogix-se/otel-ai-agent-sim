# Conventions

- `F_ws` — the only page filter (chip "Workspace", key `workspace`): `workspace_id="a"` for one value, `workspace_id=~"a|b"` for several (regex-escaped), omitted when empty. `F_user` — `user_id="…"`, emitted **only by the Member drawer** (page filter type carries `userId`, the bar never sets it). Selector order is `{F_ws,F_user,date…}`; an empty selector prints nothing.
- `{D}` — the stage-two date matcher: `date="d"` or `date=~"d1|d2"` over the distinct per-workspace snapshot dates stage one found. Snapshot date per workspace = the newer of the family's newest row `date` and its `fanout_sweep_users` date (`fanoutSnapshotDates`); rows are then kept only on their own workspace's date (`keepSnapshotRows`). Memories have no sweep: dated by `memoryDates`, dropped when `user_state` has a newer date. Non-two-stage snapshot reads keep each workspace's newest `date` client-side (`keepLatestDateBy`).
- Window: `resolveComplianceWindow(cxAiTimeRange(), Date.now())` — bounds floored to whole seconds; unusable URL bounds → last 7 days. `days = max(1, ceil(span / 1d))`. `[Nd]` = `max(days, 2)` (snapshot lookback). `[N_id d]` = `max(days, 2, 30)` (identity lookback). `[Ss]` = `max(span seconds, 60)` (counters). `[L d]` = `max(days, 90)` (connector last call). Default range = last 7 days; presets 24h / 2 / 3 / 5 / 7 / 14 days.
- Evaluation: every instant runs at `time = floor(to/1000)`; the has-data probe runs at `Date.now()`. The page calls `pinQuickModeAnchor(true)`, so in quick mode "now" is pinned once per visit (per URL range) and deferred panels resolve the same `to`. No range (matrix) query exists on this page.
- Caching: `AiCenterPromqlService` dedupes **in-flight** requests only (key = URL + params; finished responses are not kept), 30 s HTTP timeout. Both query services hold `#shared` caches (`shareReplay`, newest 20 keys, a failed read evicts its key) keyed `fromMs|toMs|filters` (raw-log snapshot reads: `toMs|filters`). Cached: roster, shared assets, app connections, app-name rows, content surface, remote-control aggregate / posture, identities, machines, chat apps, app names, agent grants. **Not cached**: has-data, workspace ids, fleet, plugins, library file sizes.
- DataPrime: `R(stream, …clauses)` = `source default/ai.raw.openai.compliance_logs | filter $d.stream == 'openai.compliance.<stream>' && <clauses>`. Archive tier, `limit 5000` (`RAW_LOG_ROW_LIMIT`), 30 s timeout (`RAW_LOG_TIMEOUT_MS`). `AiCenterDataprimeService` is injected optionally — absent ⇒ every raw-log read is null. Raw-log windows: snapshot reads `[to − 2d, to]`; grants / app names / agent connector names `[to − 90d, to]`; chat apps `[from, to]`; file sizes `[to − N d, to]`; device enrichment one read per merged `[date − 1d, min(to, date + 2d)]`.
- `W_acct(field)` = `(!field.contains('__') || field.endsWith('__<ws>') [|| …])` — keeps account-scoped ids of the selected workspaces and ids naming none. `U_acct(field)` = `field.startsWith('<user>__')`.
- Identity: metrics key members by bare `user_id` (`user-…`) + `workspace_id`; the raw log carries account-scoped ids `user-…__<workspace>` (`owner_id`, `creator_account_user_id`, `account_user_id`), stripped with `bareUserId`. Owner label = identity-metric email → raw `users` snapshot email → raw `user_id`. `{ID}` = 2 optional instants: `max by (user_id, email, name, user_email) (last_over_time(openai_compliance_user_identity{service_name!="cx-codex-compliance-puller"[,F_user]}[N_id d]))` and `max by (user_id, user_email) (last_over_time(openai_analytics_codex_credits{F_user}[N_id d]))`; directory wins. Seat key = `workspace_id|user_id`.
- Flag model: route guard + sidebar row read `ai-center-openai-administration-usage`; inside the page nothing re-reads a flag. The AISPM Code Agents shell also gates the whole outlet on detection (see Empty state).
- Fail behaviour: a failed non-optional PromQL fails its method → panel error state. `{ID}` reads are `optional` (→ empty vector, emails missing). Raw-log reads → null (columns hidden via `filledFields`, cells "—"). Insights turn each failed source into null and add an "Insights may be incomplete" card; if nothing fires and a source failed, the section errors. Has-data failure → `true` (no banner).

DataPrime readers (exact text; `[…]` = clause emitted only when the filter is set):

- `R_users` = `R(users) | groupby $d.data.id as user_id, $d.data.email as email, $d.data.name as name aggregate max($m.timestamp) as snapshot_ns`
- `R_devices` = `R(remote_control_clients [, $d.data.user_id == '<user>'] [, $d.data.account_user_id.endsWith('__<ws>') (|| per extra ws)]) | groupby $d.data.id as id, $d.data.account_user_id as account_user_id, $d.data.user_id as user_id, $d.data.device_key_protection_class as protection_class, $d.data.is_deleted as is_deleted, $d.data.device_model as device_model, $d.data.platform as platform, $d.data.os_version as os_version, $d.data.last_seen_country as last_seen_country, $d.data.last_seen_at as last_seen_at, $d.data.last_seen_bucket as last_seen_bucket aggregate max($m.timestamp) as snapshot_ns`
- `R_machines` = `R(remote_control_environments [, W_acct($d.data.account_user_id)]) | groupby $d.data.id as id, $d.data.account_user_id as account_user_id, $d.data.user_id as user_id, $d.data.name as host_name, $d.data.kind as kind, $d.data.app_server.os as os, $d.data.app_server.arch as arch, $d.data.app_server.client_name as client_name, $d.data.app_server.client_version as client_version, $d.data.app_server.originator as originator, $d.data.app_server.terminal as terminal, $d.data.app_server.connection_status as connection_status, $d.data.app_server.busy as busy, $d.data.app_server.last_seen_at as last_seen_at, $d.data.app_server.last_seen_bucket as last_seen_bucket aggregate max($m.timestamp) as snapshot_ns`
- `R_chat_apps` = `R(app, $d.data.log_type == 'request' [, $d.data.principal.id == '<ws>'] [, $d.data.actor.user_id == '<user>']) | groupby $d.data.app_id as app_id aggregate count() as calls, approx_count_distinct($d.data.actor.user_id) as users, max($m.timestamp) as last_ns, max_by($m.timestamp, $d.data.app_name) as app_name, max_by($m.timestamp, $d.data.app_type) as app_type`
- `R_app_auth` = `R(app_auth [, $d.data.principal.id == '<ws>'] [, $d.data.actor.user_id == '<user>']) | groupby $d.data.app_id as app_id, $d.data.principal.id as workspace_id, $d.data.actor.user_id as user_id, $d.data.actor.user_email as user_email, $d.data.action as action aggregate max($m.timestamp) as last_ns`
- `R_app_names` = `R(app [, $d.data.principal.id == '<ws>']) | groupby $d.data.app_id as app_id, $d.data.app_name as app_name aggregate count() as events`
- `R_agent_conn_names` = `R(custom_agents, $d.data.event_details.connector_id != null [, $d.data.principal.id == '<ws>']) | groupby $d.data.event_details.connector_id as app_id, $d.data.event_details.connector_name as app_name aggregate count() as events`
- `R_agents` = `R(agents [, W_acct($d.data.owner_id)]) | explode $d.data.definition.agent_fields.tools.connectors into $d.grant original preserve | groupby $d.data.id as agent_id, $d.data.name as agent_name, $d.data.owner_id as owner_id, $d.grant.connector_id as connector_id, $d.grant.user_approvals as approvals, ($d.grant.user_approvals.always != null || $d.grant.user_approvals.never != null) as per_action, arrayJoin($d.grant.allowed_tools, ',') as allowed_tools aggregate max($m.timestamp) as snapshot_ns`
- `R_plugins` = `R(plugins [, W_acct($d.data.creator_account_user_id)] [, U_acct($d.data.creator_account_user_id)]) | groupby $d.data.id as plugin_id, $d.data.name as plugin_name, $d.data.status as status, $d.data.creator_account_user_id as creator_id aggregate max($m.timestamp) as snapshot_ns`
- `R_files` = `R(library_files [, $d.resource.attributes.workspace_id == '<ws>'] [, ($d.data.user_id == '<user>' || $d.data.user_id.startsWith('<user>__'))]) | groupby $d.data.id as file_id, $d.data.is_trashed as trashed, $d.data.file_size_bytes:number as bytes aggregate max($m.timestamp) as snapshot_ns`
